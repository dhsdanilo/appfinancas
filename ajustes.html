    Sincronização

    Parear este aparelho

    Os lançamentos vão para um repositório privado seu no GitHub, e sobem cifrados: mesmo que alguém alcance o repositório, não há o que ler lá. Isto é de uma vez só por aparelho.

    O privado, no formato dono/nome — é o que vem depois de github.com/ na barra de endereços dele.
    Fica só neste aparelho. Nunca entra num lançamento, nunca sobe.
    Cifra os lançamentos antes de subirem. Guarde-a: perdida, a cópia do GitHub vira ilegível.
    Vira o nome do arquivo dele lá dentro.
    Como criar o token
    1. Em github.com/settings/personal-access-tokens/new, crie um token fine-grained.
    2. Repository access: Only select repositories → o repositório dos dados, e só ele.
    3. Permissions → Repository permissions → Contents: Read and write.
    4. Expiration: um ano. Token eterno é token esquecido.
    5. Copie o token e cole aqui. Ele fica só neste aparelho — nunca entra num lançamento, nunca sobe pro repositório.
    Sobre a frase secreta

    É ela que cifra os seus lançamentos antes de subirem. Precisa ser a mesma nos dois aparelhos — o app confere, e recusa a errada antes de tocar em qualquer dado.

    Se você perdê-la, a cópia do GitHub vira ilegível, e nem eu nem o GitHub podem recuperar — é exatamente a propriedade que se quis comprar. O histórico continua inteiro dentro de cada aparelho. Guarde-a no gerenciador de senhas, ou no papel que você guarda bem.

    Frase, não PIN: quatro dígitos viram chave fraca.
